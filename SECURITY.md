# Segurança e privacidade

Este é um projeto pessoal, experimental e sem garantia. Ele conversa com o fone
por Bluetooth e pode alterar configurações do dispositivo.

## Para relatar problemas

- Abra uma issue **sem dados pessoais**: nada de endereço Bluetooth completo,
  serial, capturas HCI ou nomes de dispositivos.
- Se o problema for sensível, entre em contato pelo perfil do autor em vez de
  publicar detalhes.
- Inclua modelo, firmware, versão do Windows e passos para reproduzir.

## Escopo

- O projeto não faz atualização de firmware.
- O projeto não contorna PIN, passkey, pareamento ou confirmações do Windows.
- Use apenas com dispositivos seus.
- Comece por leituras; writes só foram habilitados depois de validação com
  confirmação e reversão no hardware do autor.
