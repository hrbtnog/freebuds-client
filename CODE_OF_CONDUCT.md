# Código de conduta

Este é um espaço pequeno e amigável para aprender e melhorar um projeto pessoal.

- Seja gentil e assuma boa-fé.
- Critique ideias e código, não pessoas.
- Não publique dados pessoais de ninguém: endereço Bluetooth completo, serial,
  capturas com nomes de dispositivos, prints de conversas ou informações privadas.
- Não faça assédio, discriminação, ameaças ou ataques.
- Se alguém pedir para parar um comportamento, pare.

Problemas de conduta podem ser relatados abrindo uma issue sem dados pessoais ou
entrando em contato pelo perfil do autor. O autor pode remover comentários,
fechar issues ou bloquear contas que não sigam estas regras.
